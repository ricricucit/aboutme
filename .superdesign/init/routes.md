# Routes

- `/` — home, generated by `homePage` in `build.mjs`
- `/about/` — career story, generated by `aboutPage`
- `/cv/` — detailed CV, generated by `cvPage`
- `/one-day/` — post index, generated by `onedayPage`
- `/<lang>/...` — localized versions of the same routes

All routes share the generated header and footer. English is canonical; other languages are prefixed.
