# Theme

## Token summary

- Colors: white/near-black adaptive background and foreground; muted grays; yellow `#eecc5d` accent.
- Fonts: Maison Neue for text; Times New Roman/Times/Georgia for display and drop caps.
- Type: four sizes only: `1rem`, `1.1875rem`, responsive `1.375–1.625rem`, responsive `2.25–3.5rem`.
- Rhythm: `1.9rem` body line with quarter-, half-, one-, 1.5-, 2-, and 3-line spacing tokens.
- Measure: `48rem`; responsive gutter `1.25–2.5rem`.
- Style: editorial, restrained, border-light, light/dark adaptive.

## Raw source

The complete theme and component CSS lives in `src/style.css` and is passed directly to design drafts.
