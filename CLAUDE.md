# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

aboutme.it — Enrico Icardi's personal site. Static HTML, **no framework, no runtime JS beyond ~1 KB inline**, nine languages, light/dark/system theme. Published to GitHub Pages (custom domain via `static/CNAME`). Target: Lighthouse 100 across the board on every page — keep it that way (no external scripts and no extra fonts (sole allowed exception: the GoatCounter beacon, wired via `GOATCOUNTER` in `build.mjs`, currently off), images only as inline SVG or the existing optimised assets).

## Commands

- `npm run dev` — builds to `dist/` and serves it at http://localhost:5173 (`PORT=…` to change). Every page request rebuilds, so editing `content/*.json`, `src/style.css` or `build.mjs` shows on reload. No watcher, no install needed.
- `npm run build` — one-off build to `dist/`.
- `npm test` — the e2e gate: builds, serves on :5199, runs Lighthouse 12 (mobile + desktop) on `/`, `/about/`, `/cv/`, `/it/`, `/de/cv/` and fails unless every category is 100. Reports land in `.lighthouse/` (gitignored). Override the page list with `LH_PAGES=/,/fr/cv/ npm test`. Needs Chrome installed; `npx` fetches Lighthouse, so the repo itself has zero dependencies — there is no `npm install`.
- **Deploy = push to `main`.** `.github/workflows/deploy.yml` runs the build + `npm test`, uploads the Lighthouse reports as a workflow artifact, and publishes `dist/` with `actions/deploy-pages` (repo Settings → Pages → Source must be "GitHub Actions"; the custom domain is set there too, `static/CNAME` is kept for safety). Pull requests run the test job only.

No linter.

## Architecture

Everything is generated by `build.mjs` (Node ≥ 18, built-ins only):

- **Content** lives in `content/<lang>.json`, one file per language, identical key structure (`meta`, `nav`, `home`, `about`, `cv`, `footer`). `en.json` is canonical; the others are translations. Strings may contain inline HTML (`<a>`, `<strong>`, `<em>`, `<hr>` as its own paragraph) and the placeholders `{about}`, `{cv}`, `{book}`, which `build.mjs` resolves per language. External `<a href="http…">` links get `rel="noopener" target="_blank"` added automatically.
- **Routing:** English at `/`, `/about/`, `/cv/`; other languages under `/<lang>/…`. Language order and set come from `ORDER` in `build.mjs`; a language is included only if its JSON exists. Adding a language = add `content/xx.json` + its code to `ORDER`.
- **Pages:** `homePage`, `aboutPage`, `cvPage` in `build.mjs` — template literals, no templating engine. `head()` emits canonical, `hreflang` alternates for every language + `x-default`, OG/Twitter meta, JSON-LD `Person`, inline theme script, font preloads and the whole of `src/style.css` inlined.
- **One Day blog:** index at `/one-day/` (all languages, listed in the nav). A post is a folder `content/oneday/YYYY-MM-DD-slug/` holding one complete, art-directed standalone HTML document per language (`it.html`, `en.html`, ...), copied verbatim to `/{lang}/one-day/<slug>/` — no site chrome is injected, every post is free to look entirely different. The index extracts each post's `<title>` and takes the date from the folder name; a language without its own file links to the Italian (Italian-first) version with a marker. Posts are in the sitemap but NOT in the Lighthouse gate's page sample — each post's author is responsible for its performance.
- **Also emitted:** `sitemap.xml` (with `xhtml:link` alternates), `robots.txt`, `llms.txt`, `cv.md` per language (plain-text CV for LLM crawlers), `404.html`, and everything in `static/` copied to the root.
- **Theme:** CSS custom properties on `:root`; dark via `prefers-color-scheme` unless `<html data-theme>` is set. A `<head>` inline script applies the stored choice before paint; the footer script cycles system → light → dark on `#theme` (stored in `localStorage.theme`; removed = system).
- **Language auto-select:** only on `/` (the English home). The footer script picks the first of `navigator.languages` that matches a built language and `location.replace`s to `/<lang>/`; an explicit footer language click stores `localStorage.lang`, which wins on later visits. Bots and no-JS visitors get the full English page, so the redirect never hurts SEO.
- **Fonts:** `src/fonts/` holds Maison Neue Book (400) and Medium (500) as Latin + Latin-Ext subsets (~15 KB each). Maison Neue is a commercial font (Milieu Grotesque) — don't add weights or ship it elsewhere without a licence. Cyrillic isn't covered, so `/uk/` falls back to the system stack by design.
- **Images:** `src/img/` — portrait as a 4:5 crop at 360/720 px WebP (floated left in the home hero: 13rem on desktop, 7rem on phones; text runs around it) and `og.jpg` (1200×630 for social cards). Regenerate from a source file with Pillow if the photo changes; keep sizes small.

## Design system (`src/style.css`)

Three layers, in order: **tokens** on `:root` (colours via `light-dark()` — one definition serves both themes; `data-theme` only flips `color-scheme`), **base** element styles, **components** (`.top`, `.hero`, `.btn`, `.entry`, `ul.plain`, `footer`). Rules to keep:
- Four type sizes only: `--fs-s` `--fs-b` `--fs-l` `--fs-h`. Don't add a fifth; use weight (400/500) or colour (`--muted`, `--muted-2`) for hierarchy.
- Vertical rhythm: the body line is `--lh` (1.8rem); every margin/padding is a `--rN` step (N half-lines). No ad-hoc pixel values.
- Measure `--measure` (44rem ≈ 75 characters) and gutter `--gutter` (clamp 1.25–2.5rem) are the only layout widths.
- Hyphenation only under 40rem; `text-wrap: pretty` on paragraphs, `balance` on `h1`.

## Content rules

- `about.html` is the author's career text: change it only when asked — translations must mirror it paragraph by paragraph.
- The tagline "Engineering and Product + AI Sitter" stays in English in every language.
- The booking link, LinkedIn, GitHub and e-mail are constants at the top of `build.mjs`, not in content files.
- Private data (DOB, street address, phone) is intentionally absent from the public CV.
