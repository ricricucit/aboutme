# Changelog

All notable changes to this site. Format loosely follows [Keep a Changelog](https://keepachangelog.com/); versions follow the site's life, not semver ceremony.

## [2.0.0] — 2026-08-31

Full rebuild. The Vue/webpack stack is gone; the site is now generated by a single dependency-free Node script.

### Added
- Nine languages (en, de, it, fr, es, pt, nl, pl, uk) with hreflang alternates, per-language sitemap entries and footer switcher; one-time language auto-select on `/` from `navigator.languages`.
- Detailed CV page (`/cv/`) with sticky section labels + dates, replacing the old external HackMD link.
- "One Day" blog: index in all languages; posts are standalone, art-directed HTML files copied verbatim (zero posts at launch — it starts today).
- LLM/GEO layer: `llms.txt`, `llms-full.txt`, per-language `cv.md`, JSON-LD `ProfilePage`/`Person` with `knowsAbout`/`hasOccupation`, AI-crawler-friendly `robots.txt`.
- Light/dark/system theme, applied before paint, stored choice.
- GoatCounter cookie-less analytics.
- E2E gate: `npm test` fails unless Lighthouse scores 100 in every category (mobile + desktop) on a sample of pages; GitHub Actions runs it on every push and deploys to Pages only when green.
- MIT license for the code (fonts and personal content excluded), this changelog, README.

### Changed
- Design: editorial system — Times serif display titles and drop caps over Maison Neue text (subset, self-hosted), four type sizes, half-line vertical rhythm, 48rem measure, newspaper run-around portrait on the home page.
- Content rewritten and restructured (career narrative kept verbatim from the previous site, only translated); booking link moved to Google Calendar; site e-mail is now the work address.
- Deploys via GitHub Actions to Pages from the single `main` branch; custom domain served by GitHub with enforced HTTPS.

### Removed
- Vue 2, webpack 3, node-sass, welance-bs, PhantomJS prerenderer, `package-lock.json` — the repo has zero npm dependencies.
- Legacy `master` and `gh-pages` branches.
- Twitter link, Skype, Clarity.fm, personal data (DOB, street address, phone) from public pages.

## [1.x] — 2017–2026

- **2017** — first version in this repo: Vue 2 + webpack 3 single-page portfolio, prerendered and published to GitHub Pages (`gh-pages` branch) with the `aboutme.it` custom domain.
- **2018–2024** — the domain was served by a separate minimal rebuild (later Nuxt) maintained outside this repo; last content update January 2024.
